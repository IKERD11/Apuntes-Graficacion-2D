# 2.1. Transformación bidimensional

Las transformaciones geométricas bidimensionales permiten alterar la posición, tamaño, orientación o forma de un objeto en un sistema de coordenadas 2D. Estas operaciones son la base de la animación 2D, el diseño asistido por computadora (CAD) y las interfaces gráficas. 

Un punto en 2D se representa habitualmente como un par $(x, y)$. Un polígono u objeto más complejo se transforma aplicando la misma operación a cada uno de sus vértices, lo que preserva su conectividad.

A continuación, se describen las transformaciones básicas (o rígidas y afines).

---

## 2.1.1. Traslación
La traslación mueve un objeto de una posición a otra en línea recta, manteniendo su tamaño, forma y orientación original intactos. Se logra sumando valores de desplazamiento $t_x$ (en el eje X) y $t_y$ (en el eje Y) a las coordenadas originales.

* **Fórmula:**
  $$x' = x + t_x$$
  $$y' = y + t_y$$

**Ejemplo Analítico:**
Si tenemos un punto $P(2, 3)$ y queremos trasladarlo 5 unidades a la derecha y 2 hacia arriba ($t_x=5, t_y=2$), el nuevo punto será:
$$P'(2+5, 3+2) = P'(7, 5)$$

---

## 2.1.2. Escalamiento
El escalamiento altera el tamaño de un objeto. Al aplicar un factor de escala, el objeto no solo crece o se encoge, sino que también interactúa con su distancia al origen (al menos que se escale con un punto fijo específico).
Se multiplica cada coordenada por los factores de escala $s_x$ y $s_y$. 
- Si $s_x = s_y$, se denomina **escalamiento uniforme** (se mantiene la proporción).
- Si $s_x \neq s_y$, se produce un **escalamiento diferencial** (el objeto se estira y cambia su proporción).

* **Fórmula:**
  $$x' = x \cdot s_x$$
  $$y' = y \cdot s_y$$

**Ejemplo Analítico:**
Un cuadrado con un vértice en $P(4, 4)$ escalado por $s_x=0.5$ y $s_y=0.5$ (reducción a la mitad) se moverá al punto $P'(2, 2)$, acercándose al origen.

---

## 2.1.3. Rotación
La rotación hace que un objeto gire un ángulo $\theta$ especificado, típicamente alrededor del origen de coordenadas $(0,0)$. 
Por convención:
- Ángulos **positivos** ($\theta > 0$) producen rotaciones en sentido antihorario.
- Ángulos **negativos** ($\theta < 0$) producen rotaciones en sentido horario.

* **Fórmula (alrededor del origen):**
  $$x' = x \cdot \cos(\theta) - y \cdot \sin(\theta)$$
  $$y' = x \cdot \sin(\theta) + y \cdot \cos(\theta)$$

**Ejemplo Analítico:**
Rotar el punto $A(1, 0)$ en 90 grados ($\pi/2$ radianes). Sabiendo que $\cos(90^\circ) = 0$ y $\sin(90^\circ) = 1$:
$$x' = 1 \cdot 0 - 0 \cdot 1 = 0$$
$$y' = 1 \cdot 1 + 0 \cdot 0 = 1$$
El nuevo punto es $A'(0, 1)$.

---

## 2.1.4. Sesgado (Shear)
El sesgado distorsiona la forma de un objeto, dándole una apariencia "inclinada" (como si se tirara de lados opuestos en direcciones contrarias). Esto transforma los cuadrados en paralelogramos.  
Existen sesgados independientes en el eje X y en el eje Y.

* **Fórmula (sesgado en X, controlando con $sh_x$):**
  $$x' = x + sh_x \cdot y$$
  $$y' = y$$
  *(El valor de "x" se mueve proporcionalmente según la altura "y")*

* **Fórmula (sesgado en Y, controlando con $sh_y$):**
  $$x' = x$$
  $$y' = y + sh_y \cdot x$$

## 2.1.5. Implementación en Código (Python con NumPy y Matplotlib)
Para probar estos conceptos, podemos usar NumPy para manejar los puntos ($x, y$) en forma matricial y probar matemáticamente las transformaciones. Las funciones devuelven arreglos con las nuevas coordenadas.

```python
import numpy as np
import matplotlib.pyplot as plt

def trasladar(puntos, tx, ty):
    """Suma desplazamiento a los vectores (x, y)"""
    matriz_T = np.array([tx, ty])
    return puntos + matriz_T

def escalar(puntos, sx, sy):
    """Multiplica por factor"""
    matriz_S = np.array([[sx, 0], 
                         [0, sy]])
    return puntos.dot(matriz_S) # Multiplicación punto por matriz

def rotar(puntos, angulo_grados):
    """Aplica senos y cosenos para girar respecto al origen 0,0"""
    rad = np.radians(angulo_grados)
    matriz_R = np.array([
        [np.cos(rad), -np.sin(rad)],
        [np.sin(rad),  np.cos(rad)]
    ])
    # Como nuestros puntos son arreglos [n, 2], la multiplicacion es al revés: P * R^T
    return puntos.dot(matriz_R.T)

# ===============================
# EJERCICIO DE PRUEBA:
# ===============================
if __name__ == "__main__":
    # Definimos un cuadrado (4 vértices cerrados)
    cuadrado = np.array([
        [0, 0],
        [2, 0],
        [2, 2],
        [0, 2],
        [0, 0] # volver al origen para cerrar ciclo visual
    ])

    # 1. Rotamos 45 grados
    cuadrado_rotado = rotar(cuadrado, 45)
    
    # 2. Escalar a la mitad (0.5)
    cuadrado_escalado = escalar(cuadrado, 0.5, 0.5)
    
    # 3. Lo trasladamos +3 en X y +1 en Y
    cuadrado_trans = trasladar(cuadrado_rotado, 3, 1)

    # Gráfico Rápido
    plt.plot(cuadrado[:,0], cuadrado[:,1], label="Original", linestyle="--")
    plt.plot(cuadrado_rotado[:,0], cuadrado_rotado[:,1], label="Rotado 45°")
    plt.plot(cuadrado_trans[:,0], cuadrado_trans[:,1], label="Rotado + Trasladado", linewidth=2)
    plt.axis("equal")
    plt.legend()
    plt.grid(True)
    plt.show()
```
