# 2.4. Fractales

Los **fractales**, introducidos por Benoit Mandelbrot en 1975, son conjuntos estadísticos o formaciones matemáticas descritas mediante iteraciones (procesos cíclicos o recursivos de funciones complejas, como los puntos no euclídeos) que **carecen de un grado real entero**, ya que exhiben un tipo de estructura que crece en complejidad conforme se le hace recíproca observación (ampliación de escala).

Tienen características notables en graficación o modelado procedural:
- **Autosimilitud** (o autosemejanza): Una subparte de un fractal conserva una forma parecida o idéntica (similaridad rigurosa, cuasi-similitud) a los aspectos completos del todo geométrico.  
- **Escala de Detalles Infinity**: Si nos acercamos a las líneas fronterizas (bordes), continúan desplegando contornos irregulares al infinito sin volverse curvas suaves.

---

### Clasificación y uso

La representación y desarrollo fractal son de uso vital para producir todo tipo de aspectos de un paisaje fotorealista "por computadora" —por ejemplo: nubes densas voluminosas, líneas de costa de las playas, sistemas de venas (o los flujos de los ríos en la tierra), arboledas, y terrenos escarpados.  

**Tipos clásicos o representativos:**

1. **Autosimilitud exacta:**
   En cada nivel de la iteración se añade una parte matemáticamente análoga a la parte anterior (Ej: *Copo de Nieve de Koch*, *Polvo de Cantor* o el *Triángulo de Sierpinski*).

   *Diagrama de Copo de Nieve de Koch (L Sistema Fractal básico):*
   ```mermaid
   graph TD;
       A[Paso 0: Segmento Recto] -->|Dividir en 3| B[Paso 1: Agregar Pico central]
       B --> C[Paso 2: A cada segmento nuevo agregar otro pico]
       C --> D[Paso 3: Continúan iteraciones infinitamente]
       D --> E[Suma Fractal: Curva de Perímetro Infinito pero área finita]
   ```

2. **Fractales cuasi-similares u orbitrales de Conjuntos:**
   Calculadores en base a una cuadrícula del plano complejo donde los píxeles reaccionan calculando que un punto no escapa asintomáticamente hacia el infinito, un clásico de *Mandelbrot* o *Julia* (iteraciones de $\approx z_{n+1} = z_n^2 + c$). Estas fronteras no tienen una réplica idéntica estricta, pero están formadas por detalles que contienen remolinos similares a escalas cada vez más profundas.

3. **Fractales estocásticos:**
   Los algoritmos incorporan aleatoriedad o sistemas de ruido (Ejemplo: Perlin Noise y Fractional Brownian Motion). En el que el ruido y la perturbación disminuyen con base empírica, lo que nos otorga montículos montañosos, fuego dinámico, y el trazado geológico hiperrealista usado en motores como Unreal Engine.

### Ejercicio práctico: Implementación del Fractal Copo de Koch (Python)
Podemos aplicar un algoritmo de *autosimilitud exacta* muy simple utilizando el módulo visual `turtle` integrado en las librerías estándar de Python. Dibuja recursivamente los picos.

```python
import turtle

def curva_koch(tortuga, longitud, profundidad):
    # Condición de parada (caso base): Trazar una línea recta si la profundidad es 0
    if profundidad == 0:
        tortuga.forward(longitud)
    else:
        # Caso recursivo: Dividir el trazo en 4 lineas formando el "pico" triangular
        longitud_tercio = longitud / 3.0
        
        curva_koch(tortuga, longitud_tercio, profundidad - 1)
        tortuga.left(60)      # Gira a la izquierda para el pico
        curva_koch(tortuga, longitud_tercio, profundidad - 1)
        tortuga.right(120)    # Gira a la derecha bajando
        curva_koch(tortuga, longitud_tercio, profundidad - 1)
        tortuga.left(60)      # Se endereza para seguir su camino
        curva_koch(tortuga, longitud_tercio, profundidad - 1)

def dibujar_copo_de_nieve():
    # Configurar el lienzo de dibujo
    pantalla = turtle.Screen()
    pantalla.bgcolor("white")
    
    t = turtle.Turtle()
    t.speed(0)     # Máxima velocidad
    t.penup()
    t.goto(-150, 90) # Centrar el dibujo
    t.pendown()
    
    nivel_recursividad = 4  # Aumenta el nivel para mayor nivel de detalle fractal
    longitud_segmento = 300
    
    # El copo está compuesto por 3 curvas de Koch en forma de triángulo equilátero
    for _ in range(3):
        curva_koch(t, longitud_segmento, nivel_recursividad)
        t.right(120)

    pantalla.mainloop()

if __name__ == "__main__":
    dibujar_copo_de_nieve()
```
